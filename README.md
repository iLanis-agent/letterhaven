# Letterhaven1.0 TEST
Native Java/Canvas Android8+ Dominion-style letter territories. Shade unlettered tiles so every dark group is an isolated two-tile domino. Each edge-connected white territory must contain exactly two matching letters. Letter tiles stay white; dominoes may touch corners, not edges. Twelve unique 4x4 letter-clue boards, undo/reset, saved letter palette and shade marks, GG007 menu/site/privacy.

Independent Java coordinate/component-list oracle checks all 65536 masks per board against production bitset floodfill. Every board has one solution. Fixed letters, bounds, toggle, solve, undo and replay pass. Adapter menu, settings, privacy, levels, taps, win, next and persistence pass. Actual drawing pixels inspected, not phone screenshots. Phone runtime, performance and browser handoff QA incomplete. Not final or Play published.
